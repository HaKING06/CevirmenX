What’s new in 1.3.3

A more connected dashboard for your translation workflow.

  • Translation workspace integrated into the dashboard.
  • One interface-language menu with native language names.
  • Refined popup, responsive layout and theme styling.
  • Fixed missing shortcut help that interrupted language updates.
  • Versioned package downloads and consistent release metadata.
  • MIT license and contribution/security documentation.

Updating your extension

Store installations update through their store after approval. For manual installations, extract the new package and reload the extension folder. Downloading a ZIP alone does not install or update the extension.

The automatic release page can be disabled in the translation dashboard.
