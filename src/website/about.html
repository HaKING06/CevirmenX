A little less friction. A little more understanding.

ÇevirmenX is a browser extension by HaKING, designed to translate selected text while you stay on the page.

A focused workflow

Select a word or sentence, use Alt+T or the context menu, then read, listen to or copy the result. Use the dashboard to manage your dictionary, previous translations and preferences.

Free to use

No API key is required. Translation providers may impose service limits, and translations may contain errors. Review critical content before relying on it.
